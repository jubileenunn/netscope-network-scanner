NetScope is a lightweight Python‑based network discovery tool designed for IT technicians, sysadmins, and home lab enthusiasts. It performs a ping sweep, parses the ARP table, resolves hostnames, and stores discovered devices in a persistent SQLite inventory database.

This project gives you a clean, practical foundation for building your own IT automation toolkit.

🐈 Key Features

Network‑wide ping sweep (CIDR‑based)

ARP table parsing for MAC address detection

Hostname resolution via nslookup

SQLite‑based asset inventory

Automatic asset updates (last‑seen timestamps)

Simple command‑line interface

Cross‑platform support (Windows, macOS, Linux
